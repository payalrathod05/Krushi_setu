🌾 KrushiSetu — Smart Agriculture Assistance Platform

KrushiSetu is a modern, user-friendly agricultural support platform designed to connect farmers, administrators, and resources through a seamless digital interface.
The application is built using React + Vite, offering fast performance, modular architecture, and a clean design powered by TailwindCSS.

🚀 Features
👨‍🌾 Farmer Portal

Easy access to agricultural resources

Crop guidance & recommendations

User-friendly and lightweight UI

🛠 Admin Panel

CRUD operations for agricultural data

Product / resource management

Admin dashboard UI

⚡ Modern Frontend Stack

⚛️ React 18

⚡ Vite for super-fast builds

🎨 TailwindCSS utility-first styling

🔄 Hot Module Reloading (HMR)

🧹 ESLint with recommended rules

🛠 Installation & Setup
1. Clone the Repositor
git clone https://github.com/payalrathod05/Krushi_setu.git
cd KrushiSetu/fronted (Fronted)
cd KrushiSetu/server (backend)
3. Install Dependencies
npm install
4. Start Development Server
npm run dev (Fronted)
nodemon server.js (Backend)
Your app will be available at:

http://localhost:5173/
http://localhost:3000/

4. Create Production Build
npm run build

5. Preview the build
npm run preview

🗂 Available Commands
Command	Description
npm run dev	Start development server
npm run build	Build for production
npm run preview	Preview production
npm run lint	Run ESLint
